# Paperwork for Android

The signed APK and Ubuntu installer are on the [Paperwork downloads page](https://github.com/ishafayetul/paperwork-pdf/releases/latest). See the [installation guide](../docs/install.md) or [build instructions](../docs/build.md).

## Scan a document

1. Tap **New scan**, then choose **Take photo** or **Import photos**. Use **Continue scan** to return to an existing draft. If you start over, Paperwork asks before discarding the current draft.
2. After capture, check the detected corners. Drag the four handles if an edge is missed, then tap **Apply crop**.
3. Choose **Document** to brighten paper and improve contrast. **Original**, **Grayscale**, and **Black & White** are also available.
4. Capture more pages, rotate or reorder them, and choose **Export PDF**. Select Compact, Standard, or High quality, then save through the Android file picker.

The scanner keeps a local draft of up to 60 pages. **Images to PDF** has its own draft and uses the full, original image when importing photos. Exports use portrait or landscape A4 pages fitted to the image.

The scanner hands capture to your device’s camera app. You can import photos on devices without a camera. Scans are image-based PDFs. Markdown export requires selectable text or a prior OCR pass.

## Find exported PDFs

Tap **Saved PDFs** on the home screen to find scans and edited PDFs exported with this version of Paperwork. Tap a filename to open it in your Android PDF viewer. Paperwork remembers individual files using read-only access from the Android file picker. If a file is unavailable in the list, check the folder where you saved it.
